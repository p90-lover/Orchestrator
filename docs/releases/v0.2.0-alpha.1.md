# Orchestrator v0.2.0-alpha.1

**Experimental source release. Not a production AO replacement.**

## Changes

- Add an AO-independent native session/turn/event core backed by worker-owned SQLite, with bounded admission, deduplication, event paging and conservative restart recovery.
- Add a read-only direct Codex protocol prototype. Failed turn acknowledgements and failed output writes retire the connection instead of allowing another potentially overlapping inference.
- Add a stdio compatibility-test MCP plugin. Its synthetic test verifies durable output and event replay after storage closes and reopens, without a live model call.
- Add an isolated integration check using Coding Tools' actual MCP-server store, session configuration and the official MCP client.
- Keep the version-1 handler contract unchanged.

## Installation and limits

Requires Node 22.13 or newer. Extract the source archive to a new directory and follow `docs/native-plugin.md`. The MCP runtime uses only Node built-ins. The host integration check uses dependencies already installed in the Coding Tools checkout.

No existing chats are migrated. No provider inference is claimed. Interactive approvals, all-harness parity, provider/tool-lease integration, steering, compaction, history import and production chat cutover remain incomplete. The installed Coding Tools app continues using AO.
